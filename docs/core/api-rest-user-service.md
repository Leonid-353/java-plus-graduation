# User Service REST API

Базовый путь: через API Gateway `http://localhost:8080` или напрямую через Eureka.

## Модели данных

### User (сущность)

| Поле    | Тип    | Ограничения                         | Описание                 |
|---------|--------|-------------------------------------|--------------------------|
| `id`    | Long   | автоинкремент                       | Уникальный идентификатор |
| `name`  | String | 2-250 символов, not null            | Имя пользователя         |
| `email` | String | 6-254 символа, уникальный, not null | Email пользователя       |

---

### UserDto

| Поле    | Тип    | Ограничения             | Описание           |
|---------|--------|-------------------------|--------------------|
| `id`    | Long   | -                       | ID пользователя    |
| `name`  | String | 2-250, not blank        | Имя пользователя   |
| `email` | String | 6-254, email, not blank | Email пользователя |

### UserShortDto

| Поле   | Тип    | Описание         |
|--------|--------|------------------|
| `id`   | Long   | ID пользователя  |
| `name` | String | Имя пользователя |

---

## Эндпоинты

Все эндпоинты доступны через префикс `/admin/users`.

### 1. Создать пользователя

**POST** `/admin/users`

**Request Body:** `UserDto`

```json
{
  "name": "Иван Петров",
  "email": "ivan@example.com"
}
```

**Response:** `200 OK` → `UserDto`

```json
{
  "id": 1,
  "name": "Иван Петров",
  "email": "ivan@example.com"
}
```

### 2. Получить список пользователей

**GET** `/admin/users`

**Query Parameters:**

| Параметр | Тип                | По умолчанию | Описание                   |
|----------|--------------------|--------------|----------------------------|
| `ids`    | Collection\<Long\> | -            | Фильтр по ID пользователей |
| `from`   | Integer            | 0            | Начальный индекс           |
| `size`   | Integer            | 10           | Количество элементов       |

**Response:** `200 OK` → `Collection<UserDto>`

```json
[
  {
    "id": 1,
    "name": "Иван Петров",
    "email": "ivan@example.com"
  },
  {
    "id": 2,
    "name": "Мария Смирнова",
    "email": "maria@example.com"
  }
]
```

### 3. Получить пользователя по ID

**GET** `/admin/users/{userId}`

**Path Parameters:**

| Параметр | Тип  | Описание        |
|----------|------|-----------------|
| `userId` | Long | ID пользователя |

**Response:** `200 OK` → `UserDto`

```json
{
  "id": 1,
  "name": "Иван Петров",
  "email": "ivan@example.com"
}
```

**Ошибки:**

- `404 Not Found` — пользователь не найден

### 4. Получить краткую информацию о пользователе

**GET** `/admin/users/{userId}/short`

**Path Parameters:**

| Параметр | Тип  | Описание        |
|----------|------|-----------------|
| `userId` | Long | ID пользователя |

**Response:** `200 OK` → `UserShortDto`

```json
{
  "id": 1,
  "name": "Иван Петров"
}
```

### 5. Получить краткую информацию о нескольких пользователях

**GET** `/admin/users/short`

**Query Parameters:**

| Параметр  | Тип          | Обязательный | Описание                |
|-----------|--------------|--------------|-------------------------|
| `userIds` | List\<Long\> | да           | Список ID пользователей |

**Response:** `200 OK` → `List<UserShortDto>`

```json
[
  {
    "id": 1,
    "name": "Иван Петров"
  },
  {
    "id": 2,
    "name": "Мария Смирнова"
  }
]
```

### 6. Удалить пользователя

**DELETE** `/admin/users/{userId}`

**Path Parameters:**

| Параметр | Тип  | Описание        |
|----------|------|-----------------|
| `userId` | Long | ID пользователя |

**Response:** `204 No Content`

**Ошибки:**

- `404 Not Found` — пользователь не найден
