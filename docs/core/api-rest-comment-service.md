# Comment Service REST API

Базовый путь: через API Gateway `http://localhost:8080` или напрямую через Eureka.

## Модели данных

### Comment (сущность)

| Поле       | Тип           | Ограничения        | Описание                 |
|------------|---------------|--------------------|--------------------------|
| `id`       | Long          | автоинкремент      | Уникальный идентификатор |
| `text`     | String        | max 2000, not null | Текст комментария        |
| `eventId`  | Long          | not null           | ID события               |
| `authorId` | Long          | not null           | ID автора комментария    |
| `created`  | LocalDateTime | not null           | Дата и время создания    |

---

### CommentDto

| Поле       | Тип    | Описание                            |
|------------|--------|-------------------------------------|
| `id`       | Long   | ID комментария                      |
| `text`     | String | Текст комментария                   |
| `eventId`  | Long   | ID события                          |
| `authorId` | Long   | ID автора                           |
| `created`  | String | Дата создания (yyyy-MM-dd HH:mm:ss) |

### CommentCreateDto

| Поле      | Тип    | Ограничения         | Описание                         |
|-----------|--------|---------------------|----------------------------------|
| `text`    | String | max 2000, not blank | Текст комментария                |
| `created` | String | -                   | Дата создания (по умолчанию now) |

### CommentUpdateDto

| Поле   | Тип    | Ограничения                 | Описание                      |
|--------|--------|-----------------------------|-------------------------------|
| `text` | String | 20-2000 символов, not blank | Обновленный текст комментария |

---

## Публичные эндпоинты

### 1. Получить комментарии события

**GET** `/events/{eventId}/comments`

**Path Parameters:**

| Параметр  | Тип  | Описание   |
|-----------|------|------------|
| `eventId` | Long | ID события |

**Query Parameters:**

| Параметр | Тип     | По умолчанию | Описание             |
|----------|---------|--------------|----------------------|
| `from`   | Integer | 0            | Начальный индекс     |
| `size`   | Integer | 10           | Количество элементов |

**Response:** `200 OK` → `List<CommentDto>`

```json
[
  {
    "id": 1,
    "text": "Отличное событие!",
    "eventId": 101,
    "authorId": 10,
    "created": "2025-01-20 15:30:00"
  },
  {
    "id": 2,
    "text": "Буду обязательно",
    "eventId": 101,
    "authorId": 20,
    "created": "2025-01-21 10:15:00"
  }
]
```

## Приватные эндпоинты (пользовательские)

Базовый путь: `/events/{eventId}/comments`

### 2. Создать комментарий

**POST** `/events/{eventId}/comments`

**Headers:**

| Заголовок | Описание                      |
|-----------|-------------------------------|
| `userId`  | ID пользователя (query param) |

**Query Parameters:**

| Параметр | Тип  | Описание              |
|----------|------|-----------------------|
| `userId` | Long | ID автора комментария |

**Path Parameters:**

| Параметр  | Тип  | Описание   |
|-----------|------|------------|
| `eventId` | Long | ID события |

**Request Body:** `CommentCreateDto`

```json
{
  "text": "Отличное событие, очень понравилось!"
}
```

**Response:** `201 Created` → `CommentDto`

```json
{
  "id": 3,
  "text": "Отличное событие, очень понравилось!",
  "eventId": 101,
  "authorId": 10,
  "created": "2025-03-31 14:25:00"
}
```

### 3. Обновить комментарий

**PATCH** `/events/{eventId}/comments`

**Query Parameters:**

| Параметр    | Тип  | Описание              |
|-------------|------|-----------------------|
| `userId`    | Long | ID автора комментария |
| `commentId` | Long | ID комментария        |

**Path Parameters:**

| Параметр  | Тип  | Описание   |
|-----------|------|------------|
| `eventId` | Long | ID события |

**Request Body:** `CommentUpdateDto`

```json
{
  "text": "Обновленный текст комментария, событие было замечательным"
}
```

**Response:** `200 OK` → `CommentDto`

```json
{
  "id": 3,
  "text": "Обновленный текст комментария, событие было замечательным",
  "eventId": 101,
  "authorId": 10,
  "created": "2025-03-31 14:25:00"
}
```

### 4. Удалить комментарий (пользователь)

**DELETE** `/events/{eventId}/comments`

**Query Parameters:**

| Параметр    | Тип  | Описание              |
|-------------|------|-----------------------|
| `userId`    | Long | ID автора комментария |
| `commentId` | Long | ID комментария        |

**Path Parameters:**

| Параметр  | Тип  | Описание   |
|-----------|------|------------|
| `eventId` | Long | ID события |

**Response:** `204 No Content`

## Административные эндпоинты

Базовый путь: `/admin/comments`

### 5. Получить все комментарии (админ)

**GET** `/admin/comments`

**Query Parameters:**

| Параметр | Тип     | Описание             |
|----------|---------|----------------------|
| `from`   | Integer | Начальный индекс     |
| `size`   | Integer | Количество элементов |

**Response:** `200 OK` → `List<CommentDto>`

### 6. Удалить комментарий (админ)

**DELETE** `/admin/comments/{commentId}`

**Path Parameters:**

| Параметр    | Тип  | Описание       |
|-------------|------|----------------|
| `commentId` | Long | ID комментария |

**Response:** `204 No Content`

## Feign эндпоинты (межсервисное взаимодействие)

Базовый путь: `/comments/feign`

| Метод | Endpoint          | Описание                                      |
|-------|-------------------|-----------------------------------------------|
| GET   | `/comments/feign` | Получение комментариев события (с пагинацией) |

### 7. Получить комментарии события (Feign)

**GET** `/comments/feign`

**Query Parameters:**

| Параметр  | Тип     | Описание        |
|-----------|---------|-----------------|
| `eventId` | Long    | ID события      |
| `page`    | Integer | Номер страницы  |
| `size`    | Integer | Размер страницы |

**Response:** `200 OK` → `List<CommentDto>`
